# AI Builder — Minecraft Java 1.21.11

Клиентский Fabric-мод, который превращает сообщение `построй ...` в команды Minecraft.

## Что нужно

- Minecraft Java Edition 1.21.11
- Java 21
- Fabric Loader 0.19.5
- Fabric API 0.141.6+1.21.11
- OpenAI API key с доступом к Responses API

Fabric подтверждает для 1.21.11 Java 21 и Loader 0.19.5. Проект использует Fabric API 0.141.6+1.21.11.

## Как это работает

1. Мод перехватывает обычный чат, если сообщение начинается с `построй `.
2. Описание отправляется в OpenAI Responses API.
3. AI возвращает строго JSON со списком Minecraft-команд.
4. Мод выполняет команды через клиентское соединение Minecraft.
5. `fill`, `setblock`, `clone`, а также команды для создания командных блоков могут использоваться, если это требуется описанием.

Примеры:

    построй современный дом 15 на 20 блоков, два этажа, плоская крыша

    построй маленький средневековый замок с башнями

    построй японский дом с садом и прудом

    построй механизм из командных блоков, который открывает дверь при нажатии кнопки

## API key

Не вписывай ключ в исходный код.

### Windows PowerShell

    $env:OPENAI_API_KEY="sk-..."

После этого запускай Minecraft из того же окружения.

### Windows CMD

    set OPENAI_API_KEY=sk-...

### Linux/macOS

    export OPENAI_API_KEY="sk-..."

Ключ передаётся напрямую из мода в `https://api.openai.com/v1/responses`.

## Сборка

Проект рассчитан на Gradle/Fabric Loom.

    gradle build

Готовый мод появится в:

    build/libs/

Используй remapped production jar.

## Установка

Положи jar в папку:

    .minecraft/mods/

Также положи совместимый Fabric API jar.

В мире/на сервере у игрока должны быть права на команды, которые AI генерирует. В одиночной игре включи `Allow Commands`.

## Важное ограничение

Мод не видит содержимое мира автоматически. AI получает только твоё текстовое описание и строит относительно позиции игрока. Поэтому для точной работы на неровном рельефе или рядом с существующими постройками лучше позже добавить сканирование блоков.
